# RIATIGA Audio

RIATIGA Audio es una aplicación móvil desarrollada en Android Studio para la asignatura Desarrollo de Aplicaciones Móviles Nativas.

El proyecto corresponde a una tienda virtual de audífonos y fue realizado utilizando Kotlin y archivos XML para las interfaces.

## Funciones principales

La aplicación cuenta con tres tipos de usuario:

- Comprador.
- Vendedor.
- Administrador.

El comprador puede consultar productos, ver su detalle, agregarlos al carrito, realizar una simulación de pago y consultar su perfil.

El vendedor puede gestionar productos, consultar pedidos y actualizar su perfil.

El administrador puede gestionar usuarios y productos, además de consultar un reporte de ventas.

También se incluyeron funciones como pantalla de inicio, recuperación de contraseña, autenticación biométrica y navegación entre las diferentes pantallas.
